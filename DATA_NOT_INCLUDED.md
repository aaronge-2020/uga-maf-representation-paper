# Data Not Included

The following local files or directories were intentionally excluded from the public GitHub repository.

| Local path | Reason |
|---|---|
| `results/work/` | Runtime work directory; regenerated or copied transient artifacts, not required for public release validation. |
| `results/cache/` | Feature caches excluded to minimize repository size; regenerated by the workflow. |
| `results/checkpoints/` | Runtime checkpoints excluded to minimize repository size; regenerated by the workflow. |
| Active assets listed in `LFS_MANIFEST.csv` | Mirrored in the sibling `../github_exports_datasets/` folder for upload outside ordinary Git history. |
| Optional downloaded/raw supplemental datasets | Moved to the sibling `../github_exports_datasets/` Hugging Face-ready bundle using readable paths such as `datasets/`, `references/`, `resources/`, `results/`, and `caches/`. See `manifests/dataset_assets_manifest.csv`, `manifests/huggingface_asset_manifest.csv`, and `../github_exports_datasets/dataset_assets_manifest.csv`. |
| Superseded exploratory feature sets, stale endpoint variants, previous manuscript-output, zero-byte, and generated project-output artifacts | Removed from active release curation per the latest Bio MAF v4/latest-results scope. |
| `scratch/`, `.benchmarks/`, IDE/tool directories | Local diagnostics or tool metadata, not part of the reproducible manuscript bundle. |
