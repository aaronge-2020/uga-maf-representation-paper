# Public Data Notice

This public repository includes the curated active inputs selected for reproduction of the manuscript figures and tables. Downloaded/raw/external datasets that are too large or too broad for ordinary Git history are stored in the sibling `../github_exports_datasets/` bundle.

The sibling dataset bundle includes active dataset-backed assets plus optional external-project datasets discovered during cleanup. Verify upstream redistribution terms before public hosting, especially COSMIC signature resources and any TCGA/GDC-derived files.

See `DATA_MANIFEST.csv` for checksums and source categories for every included file.
See `manifests/dataset_assets_manifest.csv` for the dataset-bundle manifest, and `DATA_NOT_INCLUDED.md` for intentionally excluded obsolete files.
