# Deviations and amendment log

Protocol: `protocol_v1.0.md` (fixed 2026-10-25 before new outcome comparisons). Entries are chronological. Amendments made before the affected outcomes were computed are marked PRE-EXECUTION.

1. PRE-EXECUTION (2026-10-25). Event eligibility pinned to the named protein-affecting Variant_Classification set (Missense_Mutation, Nonsense_Mutation, Frame_Shift_Del, Frame_Shift_Ins, In_Frame_Del, In_Frame_Ins, Splice_Site, Nonstop_Mutation, Translation_Start_Site). Silent is excluded, matching the CPEM protein-altering definition and the Bio MAF functional-event definition in code. Bio MAF's own aggregate features apply no such filter; the difference is recorded in the audit report.
2. PRE-EXECUTION (2026-10-25). R5 formula changed from a smoothed draft variant to Ozcan Simsek 2019 Eq. 1 and Eq. 2 exactly (raw-count tf, idf = log(N_train / df_train), natural log), after the literature crosswalk established the published equations.
3. PRE-EXECUTION AMENDMENT v1.1 (2026-10-25). Canonical split. The protocol first adopted the OOF fold assignment generically, then defined a fresh StratifiedKFold split (seed 20261025). The audit then established that (a) archived runs each used their own partition, and (b) the repo convention for a canonical split is the OOF (signatures_plus_MAF_stack, xgboost) triple per endpoint. The benchmark now uses that convention split for both primary tasks (`config/canonical_split_*.csv`, provenance and hashes in `config/split_provenance.json`). One baseline cell (HRD, spectra, elastic net) had been completed on the superseded split; its pooled Spearman was 0.5132. That cell was deleted and rerun on the canonical split. No primary contrast had been computed at the time of the switch.
4. PRE-EXECUTION AMENDMENT v1.1 (2026-10-25). R6 status. The protocol first treated the Bio MAF matrix as absent (feature caches were excluded from the repo) and planned to carry R6 through archived tables only. The inventory found the real matrix at `results/tables/quick_bio_maf_features.csv.gz` (10,224 x 948). R6 is therefore a first-class refit representation under the same tuning rules as every other cell. Archived R6 values remain the reference for cross-checking the refits.
5. ENVIRONMENT (2026-10-25). XGBoost 3.0.5 is used for new runs because the repo pin (1.6.2) has no Python 3.12 wheels. All other core libraries match the repo pins. Archived results were produced under 1.6.2; small numerical differences between archived and refit values for identical configurations are expected and are not, by themselves, evidence of an error. XGBoost 3.x also rejects the bracket characters in spectra column names, so runners pass value arrays and keep feature names in sidecar tables.
6. TUNING DESIGN (2026-10-25, fixed in protocol). Model selection uses one shared stratified inner holdout (20 percent of each outer training partition, seed 20261025) instead of inner 5-fold cross-validation, because of the 2-core compute envelope. The holdout is identical for every representation and learner, and all tuning stays inside outer training data. Elastic net and XGBoost use the same selection rule. This is a budget decision, recorded here rather than discovered later.
7. NOT RUN, with reasons. CADD-weighted representation: no licensed CADD score source matched to the event calls exists locally (blocked, see status table). MuAt reruns: no GPU on this machine and the archived runs are complete; audit only. Burden-normalized count sensitivity: dropped in the protocol to keep the sensitivity family small; log1p sensitivity retained.
8. BUDGET AMENDMENT v1.2 (2026-10-25, before any primary outcome under the tuned grid). Measured cost on this machine: one full-train XGBoost fit on the cancer Sig+MAF matrix (7,040 x 1,130) takes 147 s at 242 trees; the first grid cell exceeded 90 minutes without completing, so the 46-cell grid as first specified (1,200-tree cap) is not executable here. Changes, applied uniformly and recorded before the revised grid runs: XGBoost n_estimators cap 1,200 to 400 with early stopping 40 rounds; trial count stays 10 per outer fold for all primary combined and reference cells and for all HRD cells, and is 6 for cancer alone arms and extension cells (all-gene, log1p). The first, interrupted queue run produced no completed cell and no primary outcome. A single random-configuration smoke fit on cancer fold 1 (balanced accuracy 0.769) is a timing probe only and is not a result.
